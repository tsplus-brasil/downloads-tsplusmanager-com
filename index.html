Managed servers

TSplus Manager Worker

A lightweight Windows executable you install on each TSplus server you want to manage. The Worker links the server to TSplus Manager, so you can push commands, read sessions and stream logs remotely.

Worker for Windows Server

Windows Server 2016–2025 · runs as a service · 64-bit

  • Install once on every TSplus server under management
  • Secure channel to TSplus Manager — commands, sessions & logs
  • Runs quietly in the background as a Windows service
